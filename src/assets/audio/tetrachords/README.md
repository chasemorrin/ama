# Tetrachord chord clips

Drop your 2-second piano chord recordings in this folder — that's it.

Supported formats: `.mp3`, `.wav`, `.m4a`, `.ogg`
Naming: anything you like, e.g. `chord-01.mp3`, `Cmaj-close.wav`.

The "Sing Tetrachord in Harmony" page automatically picks up every audio
file in this folder when the site is built — you never need to touch any
code. Just add files here, then run `npm run build` (or push to GitHub if
you've set up the included auto-deploy workflow) to publish them.
